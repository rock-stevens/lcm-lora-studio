There are two checkboxes, 'Increment' and 'Same Seed (Single Image)'

If the 'Increment' is checked, no randomization, and the seed is incremented by 'Amount', 'after' the first image. Therefore uses selected seed as the starting seed. If 'Amount is negative, the seed will decrement by that amount.

If the 'Increment' is unchecked, image generation always uses a random seed.

If the 'Same Seed (Single Image)' is checked, uses the selected seed as starting seed. So, the first image will always have the selected seed. Elsewise it starts on a random seed and selected seed is not used.

Also, If the 'Same Seed (Single Image)' is checked, uses the selected seed as a starting seed when generating multiple images.
