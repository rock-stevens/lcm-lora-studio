Add LoRA Models Tab.

Once you've downloaded a LoRA model for style or drawing, or whatever you downloaded it for, you've saved it into LoRA models folder, 'lora_models'.

Hit the refresh button beside the model list dropdown and select it from the list.

Adjust the LoRA scale to the amount that you want and you click the icon with the plus sign and the circle around it.

That adds the LoRA weight.

It won't work if there's no model loaded, and it'll warn you. You can't add a LoRA to an empty pipeline.

There's a refresh button down by the 'Loaded LoRA Models' drop down that will list all the models that are loaded. I keep up with what's loaded and their weights outside of diffusers and the whole library. Reasons will be coming in future versions but I don't rely on the library to tell me what weights are loaded and what their weights values are.

But if you want to change the weight of a loaded LoRA model, select it in the 'Loaded LoRA Models' drop down box. Adjust the weight to what you want it set to. Click the bottom right button right beside the drop down button right below the refresh that will change the weight. It'll indicate it.

The one that looks like a trash can will delete all the LoRAs you have loaded.

When you save your 'base' model as an LCM-LoRA model. That's when, 'any' LoRA weights, all of them. The LCM ones, any of them that you've added for style, every single one of them gets, 'fused to the model' when saved.

It's the same method used for the LCM-LoRA weights for the faster 4-Step inference, they get fused to the model and saved with it.

Although this part (Add Lora Tab) of the 'User Interface' is fairly straightforward, it will change in a future version and will get better because I don't even like it. But it's functional. It was simply built (quite a while back) on the left side of the 'bell curve' learning Gradio, that's all. When I re-do it, You will also be able to delete individual LoRAs you have loaded, rather than all of them at once.

Make sure you checkout the Screenshots for this tab, because I added a lot of notes on it.
