LCM-LoRA Studio - Help - System Model Information

  • Help - Index

System Models are the models used to perform certain background operations in LCM-LoRA Studio.

Most all programs simlar to this have them.

For example, a model is used to perform a 'depth-map' operation using Transformers, where the output image is to be used as the input for a 'depth-map' type of ControlNet.

First, you need one model right now to perform the 'depth-map' operation.
When you do perform the 'depth-map' operation, the program will load the model and perform the operation on your image.
If you do not already have the model, it will be downloaded from Huggingface. It will then be stored in your Huggingface Cache Folder. If you already have the model in your Huggingface Cache Folder, it just loads it and uses it.

This is the basic operation for loading all models you did not use this program to create and save. If a needed model is not in your Huggingface Cache, when the program tries to load it, the program goes and gets it. Once you have it, it will not need to be 'downloaded' again. Once you have them all, you can have 100% OFFLINE operation of LCM-LoRA Studio.
Models created and saved by this program via the 'Save LCM-LoRA Model' function, are not saved in the Huggingface Cache Folder because they did not come from Huggingface.

After that, guess what??
You still need the 'depth' ControlNet model, and a base' model for inference. That's two more models. Which is three total, just to do a 'depth-map' type of ControlNet and make the input image for it.

Note: The 'base' model is not counted as a 'System Model'. With the exception of a few base models like the Original SD1.5 and SDXL 1.0 models. They are base models, but they are also used as a reference model for so many other models, those are considered 'System' models as well. There are only a few that fall into this category, which are basically the 'first' model for any particular 'pipeline' Which can be used for image generation as well.

In total there are 18 'System' models referenced, of these, 6 are 'base' models, which can also be used for inference.
There are 2 models which are the LoRA models you add to a pipeline to make it an LCM-LoRA type of model for the faster 4-step inference. One of those 2 LoRA models are added for SD 'base' models, and the other for SDXL 'base' models.

The rest of the 'system' models are for the ControlNet pipline. One for each type of ControlNet.

Here's a simple table describing all of the 'system' models and their use. NOTE: We only download Safetensors.

WARNING: In total, they weigh in at around 105GB of storage space !!
