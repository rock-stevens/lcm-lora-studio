The Memory Display was added with v1.5 to show memory and swap usage.



Refresh Memory Display Only, just refreshes the display. Can be clicked most anytime, even during inference.


Refresh Display/Free Memory, Refreshes the display and tries to free as much memory.
NOTE: Continued clicking will not keep computer from crashing if you did not have enough RAM to begin with. :)
May actually end up taking it out, because it is so far working ok without clicking it.


Delete Model/Pipeline, just clears the Pipeline and therefore frees up the memory that was being used.

Overall Memory Usage in this app.

When any of these actions are performed:
  • Right 'before' loading a base model (not a LoRA Model)
  • Right 'after' saving a base model ('LCM-LoRA' weights added or not)
  • Manually delete the pipeline via GUI button.
The following happens:
  1. Deletes the LoRAs that have been loaded into the pipeline.
  2. The 'pipeline' is deleted to free any memory used.
  3. The 'operation' from the 'list above' is carried out.
So, you DO NOT need to keep clicking the 'Refresh Display/Free Memory' button !!
If you see the display turn RED, it's ok to hit it once I guess.
